# N'alimentez plus vos classes actuelles

Les classes visibles aujourd'hui sur la plateforme sont celles de l'année écoulée.
Merci de ne plus y déposer de fichiers : supports de cours, sujets, corrigés, listes
d'étudiants.

## Ce qui se passe le lundi 7 septembre

Nous migrons la plateforme vers les classes de l'année **2026-2027**. Les classes de
l'année précédente seront archivées, et les nouvelles créées avec leurs effectifs à jour.

Un fichier déposé d'ici là dans une ancienne classe part à l'archive avec elle. Vous
devrez le redéposer vous-même dans la nouvelle.

## Ce que vous pouvez faire dès maintenant

- Préparez vos supports **hors de la plateforme**, sur votre poste ou votre espace partagé.
- Vérifiez que vos anciens documents sont bien récupérés si vous comptez les réutiliser.
- Attendez le 7 septembre pour tout dépôt destiné à l'année qui commence.

## Après la migration

Vos nouvelles classes seront prêtes le lundi 7 septembre dans la journée. Vous pourrez
alors y déposer vos fichiers et inscrire vos étudiants.

Une question, un cas particulier, un document urgent à mettre à disposition avant cette
date : écrivez-nous, nous trouverons une solution.
