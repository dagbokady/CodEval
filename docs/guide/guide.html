A.5 Étape 3 « Correction » : les jeux de tests des exercices 2, 3 et 4

Un test fait tourner l’algorithme de l’étudiant avec des valeurs choisies, puis compare ce qu’il affiche à ce que vous attendez. Seuls les exercices pratiques passent par cette étape : la simulation se corrige sur son tableau.

Vue d’ensemble

  1. 1La colonne de gauche liste les exercices à tester. Cliquez sur celui à régler.
  2. 2Le compteur « Prêts à être corrigés » : 0 / 3 au départ.
La comparaison « Nombres affichés »
Avec ce mode, vous n’écrivez que les nombres attendus à la fin de l’affichage. Les invites (« Entrez le nombre numéro 1 : ») et les phrases de l’étudiant sont ignorées : Le plus grand est : 15 / C’était le n° 3 passe pour 15 3. Les décimaux s’écrivent avec un point ou une virgule (4,50 = 4.5).

C.4 Étape 3 « Correction » : le programme en cinq fichiers

L’exercice de code se corrige de deux façons : les déclarations que la copie doit contenir (structures, fonctions avec leur signature), puis les tests qui compilent et lancent le programme entier.

Vue d’ensemble

  1. 1Le seul exercice pratique de l’examen.
  2. 2Questions et QCM : rien à régler ici.

Ajouter une déclaration

  1. 3Cliquez sur + Ajouter une déclaration, puis Structure attendue pour Note et Etudiant.
  2. 4Fonction attendue pour les trois fonctions.

Les structures

  1. 5Le nom de la structure : Note.
  2. 6Le champ note, de type Décimal simple précision (float). Un champ existe déjà : + Champ en ajoute d’autres.
  3. 7Pour Etudiant, le champ note est de type Autre type : écrivez Note, comme en C.
  4. 8La déclaration telle qu’elle sera cherchée dans la copie.

Une fonction

  1. 9Le nom exact : AjouterNote.
  2. 10Retourne : Rien (affiche seulement), c’est-à-dire void.
  3. 11+ Paramètre : ValeurNote (Décimal simple précision), puis UnEtudiant.
  4. 12UnEtudiant : Autre type, puis Etudiant *.
  5. 13La signature vérifiée à la compilation.

Les deux autres fonctions

  1. 14float MoyenneNotes(Etudiant *TabEtudiants, int n).
  2. 15void AfficherTout(Etudiant *TabEtudiants, int n).

Ajouter un test

  1. 16+ Ajouter un premier test. Les fonctions reçoivent un Etudiant * : un test ne peut pas les appeler seules, il lance le programme entier.

Remplir le test

  1. 17Le test compile tous les fichiers et lance le programme.
  2. 18Trois valeurs de type Chaîne, une par étudiant : E001 Kone 12, E002 Yao 16, E003 Traore 11.
  3. 19Arguments de la ligne de commande : 3. Il remplace le 40 de ProgrammeMoyenne.exe 40.
  4. 20Écran : 13, la moyenne (12 + 16 + 11) / 3.
  5. 21Comparaison : Nombres affichés. Seule la moyenne, dernière valeur affichée, est vérifiée : la présentation de la liste reste libre.

Les deux tests

  1. 22Dupliquez pour un second test : argument 1, valeur E010 Awa 20, écran 20.

C.5 Étape 4 « Points & publication »

Les points

  1. 112, 3 et 5.
  2. 2Total : 20 / 20.

Le détail du barème de l’exercice 1

  1. 3Cliquez sur Détail du barème.
  2. 4Cochez Peser chaque ligne moi-même. Sinon, les 12 points se partagent à parts égales entre les sept lignes.
  3. 5Note 2, Etudiant 2, AjouterNote 1, MoyenneNotes 0,5, AfficherTout 0,5 : 6 points de déclarations. Puis 3 + 3 points de tests.
  4. 6Le barème de l’exercice : 12 / 12.

Publier

  1. 7Enregistrer et publier.
  2. 8ou Lancer la session.

Aide-mémoire

Avant de publier

  • La classe est choisie à l’étape 1, sinon l’épreuve reste un brouillon invisible.
  • Chaque exercice pratique est coché en vert à l’étape 3.
  • L’ordre de saisie des données est écrit dans l’énoncé quand il y en a plusieurs.
  • Le total des points fait 20 à l’étape 4.
  • L’aperçu, à droite de l’étape 2, montre le sujet tel que l’étudiant le recevra.

Après l’épreuve

À la clôture, lancez la correction. Les questions sans réponse listée vous sont signalées pour une correction à la main. Sur chaque copie, Modifier la note de cet exercice permet un ajustement (le point de propreté, par exemple), enregistré avec son motif. Publiez ensuite les résultats : les étudiants voient leur copie annotée et, si l’épreuve le propose, le corrigé.

Réutiliser un exercice. « Enregistrer dans la banque », sous chaque exercice, le range dans votre banque. Il se retrouve ensuite avec « Importer depuis la banque » dans une autre épreuve.
